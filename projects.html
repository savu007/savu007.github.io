Bae Lab, Cornell · November 2026–present

Magnonic dynamics for physical computing

Undergraduate researcher · PI: Youn-jue Bae · Advisor: Nicholas J. Brennan

I research optically driven nonlinear magnonic dynamics in CrSBr for spintronic computing. Using Fourier-transform feature extraction and linear machine learning, I analyzed double-pump optical reflectance data and demonstrated 100% linear separability of XOR states in the analyzed data as a proof of concept for physical reservoir computing.

Fourier analysis · Machine learning · Physical reservoir computing

CoMSAIL, Cornell · August 2026–present

Learning to forecast turbulent flows

Undergraduate researcher · PI: Jian-xun Wang · Advisor: Meet Hemant Parikh

I'm developing spatiotemporal Vision Transformers for multi-step turbulent flow forecasting, using sliding windows and multi-GPU training. I investigate prediction-error and physics-informed losses to improve forecast accuracy, physical consistency, and turbulence statistics.

I'm also experimenting with patch-based, pyramidal flow-matching models to generate turbulent fluid snapshots that reproduce fine-scale spatial structures.

Vision Transformers · Flow matching · Scientific machine learning

Forecasting code · Flow-matching code

Cornell Quantum Computing Association · September 2025–present

Photonic memory and quantum error correction

Hardware subgroup team member

I research higher-temperature photonic memory and hardware-based error correction. I developed and communicated the theory behind electron–nuclear spin-coupling simulations, then collaborated on a parameter search to maximize coupling strength.

I'm creating a functional model of an FPGA-based local implementation clustering decoder for the surface code, to verify the correctness of an RTL SystemVerilog design.

Spin-coupling simulations · Surface codes · FPGA verification

Summer Science Program · June–August 2024

The orbit of asteroid 1999 JN3

High school research program intern · Las Cruces, New Mexico

I developed a Python program to determine the short-term orbit of the Mars-crossing asteroid 1999 JN3 and estimate orbital uncertainty using Monte Carlo methods. Using REBOUND symplectic integrators, I studied its long-term orbital dynamics and calculated the likelihood of impact events over the next 50 million years.

Python · REBOUND · Monte Carlo methods · Orbital dynamics
